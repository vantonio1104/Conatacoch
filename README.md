# Conatacoch
Push y comits sobre el proyecto

App Android (Kotlin + Jetpack Compose + Material 3) de la Confederación Nacional de Taxis
Colectivos de Chile. Prototipo universitario (INACAP) con dos perfiles, pasajero y conductor,
y datos de ejemplo (sin backend todavía).

- Vistas de Figma: `docs/figma/`
- Contexto, convenciones y guía visual: `CLAUDE.md`

## Compilar y probar

```bash
./gradlew assembleDebug        # APK de debug
./gradlew testDebugUnitTest    # pruebas JUnit
```

Cuentas de prueba: `camila.reyes@correo.cl` (pasajero) y `p.soto@correo.cl` (conductor),
contraseña `colectivo-demo-2026`.
